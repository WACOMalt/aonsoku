  <h3 align="center">Aonsoku-BS</h3>
  <p align="center">
    A personal fork of Aonsoku, the modern desktop client for Navidrome/Subsonic servers built with React and Electron. This fork adds Mobile support, synced Jams with navidrome accounts, Session transfer and some QoL features like gapless playback, infinite scrolling on lists and posters views, and probably some other stuff.  
    
LLMs are used in the creation of this fork and as such I cannot recommend anyone use it over the official project. While I do my best to maintain quality I'm one guy with an AI, so temper your expectations. I do plan to continue keeping this fork up to date, as I use it myself. I hope you enjoy the additional functionality!
Feel free to report issues. I will attempt to address them.
